# 0001: Record architecture decisions

**Status:** Accepted

## Context
This project exists to build architecture judgement. Judgement is only visible when the
reasoning is written down, and only reviewable when it's written down *before* hindsight.

## Decision
Use lightweight ADRs (Michael Nygard format): Context, Decision, Consequences. Keep them under a page.

## Consequences
- Every week of the plan produces at least one ADR or lab write-up.
- Writing an ADR is also communication practice: one clear decision per document, readable by someone who wasn't there.
